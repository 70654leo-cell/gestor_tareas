¿Cuál es la diferencia entre Git y GitHub?
R= Git es lo que gestiona el software de un código de computadora, y github es la plataforma en la nube que ayuda a colabrorar con más desarrolladores

¿Qué función cumple el área de stage?
R=Permite seleccionar que cambios se desean incluir en un próximo commit

¿Cuál es la función del archivo .gitignore?
Es un archivo que indica que archivos y/o carpetas se quieren ignorar para no subirlos al repositorio

¿Qué relación existe entre el repositorio local y el repositorio remoto?
El repositorio local vive en el disco duro de la computadora, y el remoto vive en un servidor en la nube

¿Qué diferencia existe entre ejecutar commit y ejecutar push?
R=El commit toma los cambios que se encuentran en el area de stage y el push toma los commits acumulados y los sube a un repositorio remoto a travéz de internet, quedan visibles para el equipo y respaldos de nube
